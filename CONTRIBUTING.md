# Mitmachen

## Ablauf

1. Vor dem Arbeiten immer aktuelle Version holen:

```bash
git pull
```

2. Aenderungen machen.
3. Alles speichern und committen:

```bash
git add .
git commit -m "Kurze Beschreibung"
```

4. Aenderungen hochladen:

```bash
git push
```

## Gute Commit-Nachrichten

Schreibt kurz, was geaendert wurde, zum Beispiel:

```bash
git commit -m "Add login page"
git commit -m "Fix button styling"
git commit -m "Update README"
```

## Wenn etwas schiefgeht

Vor groesseren Aenderungen am besten kurz im Team absprechen, damit nicht alle gleichzeitig dieselbe Datei bearbeiten.
